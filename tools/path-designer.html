How to draw:
1. Click Set Start → click a cell
2. Click Draw → click any cell to extend the path along that axis
3. Undo removes the last segment; click a segment's ✕ to delete it
4. Generate JSON then copy into config.js

Violation rules:
🔴 Red cells = two parallel runs directly adjacent (add a gap row/col between them)
✅ Corners where horizontal meets vertical are not violations — the inner corner cell is fine; only the outer side needs 2 empty cells clearance

Space count: the engine uses the path length directly — any count works, not just 20/40/60. The target shown is just a guideline.
